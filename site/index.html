How this site runs

Serverless on AWS, deployed with no stored keys

Browser
  └── CloudFront (HTTPS, OAC, security headers)
        ├── /*      → S3 (private bucket: HTML, CSS, JS)
        └── /api/*  → API Gateway (HTTP API)
                        └── Lambda (Python) → DynamoDB (visitor counter)
  • Terraform provisions every resource; state in an encrypted S3 backend with locking.
  • GitHub Actions deploys on push to main through OIDC: a 1-hour role that can only sync this bucket and invalidate this distribution.
  • Same-origin API: CloudFront routes /api/* to API Gateway, so no CORS and no public API URL in the page.
  • Abuse limits: API throttling and Lambda reserved concurrency cap what a bot can cost.
